1. How to use this contract

Define variables, domains and units at first use. Give a brief reminder when a symbol changes role. Established linear algebra can be consulted in LA; the physics inner-product convention is shared. A textbook’s different signs or normalization are converted explicitly, never mixed silently.

All essential MMP arguments belong to the study path, including named LA readings where appropriate. A result proved in the notes carries no status mark: proved is the default. Mark only a statement given without a proof: cited (its reference, with the precise result and hypotheses, stays in the statement) or sketched (the missing step is named; \statustag{sketched}). Later text that uses a cited statement names it but does not repeat that it is unproved, and results proved with its help carry no mark (author’s rulings, 11 November 2026).

Use semantic macros from the registry. Their arguments use ordinary braces; the common delimiter macros auto-size. Macros that space themselves are not padded by hand:  ⁣d\ddd is an operator with its own thin space, so write ∫01f(x) ⁣dx,\int_0^1f(x)\dd x∫01​f(x)dx, never f(x)\,\dd x (author ruling, 10 November 2026). Starred/optional-size variants from other packages are not part of this initial API. Add a shared macro centrally rather than redefining one in a lecture.
