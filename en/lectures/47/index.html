Constraints and several dependent functions

Lecture objectives

We construct constraint-preserving variations and prove the constant-multiplier equation under a nonzero constraint derivative. We derive the equations for several functions and determine a fixed-length circular graph from its endpoint data.

A fixed length restricts which changes of a curve are admissible. We extend Lecture 46’s fixed-endpoint calculus to such restrictions. The stages are an integral constraint and its multiplier (Sections 47.1–47.2), several functions and pointwise constraints (Sections 47.3–47.4), and the circular extremal of fixed-end Dido (Sections 47.5–47.6), which uses only the first stage.

47.2 Euler’s constrained-variation theorem

Normality supplies a direction that corrects an error in the constraint value.

Definition 47.3 (Normality). A feasible path yyy is normal for CCC if there is a direction ζ∈V\zeta\in\mathcal Vζ∈V such that δC ⁣[y;ζ]≠0.\firstvar{C}{y}{\zeta}\ne0.δC[y;ζ]=0.(47.5) A path where this first variation vanishes for every direction is called abnormal.

Normality asks for one nonzero derivative. It does not require every direction to have one. For a C2C^2C2 path, Lecture 46’s Euler–Lagrange theorem says that normality is equivalent to failure of the Euler–Lagrange equation for CCC in the full endpoint class.

Summary

A constraint restricts exact families of paths. Its linearized equation restricts their tangents. Normality supplies one fixed correction direction. At a constrained stationary path, the correction yields the constant multiplier.

  • Integral constraint: a normal C2C^2C2 constrained stationary path satisfies Euler–Lagrange for F+λcG,F+\lambda_cGF+λc​G, with one constant λc.\lambda_cλc​.

  • Several functions: independent component directions give one Euler–Lagrange equation per coordinate, with the boundary sum displayed first.

  • Pointwise constraint: for two functions and one constraint g=0,g=0g=0, a C2C^2C2 constrained stationary path with a nonvanishing position gradient satisfies the multiplier equations with a continuous function λh(x).\lambda_h(x)λh​(x).

  • Fixed-end Dido: for 2a<ℓ<πa2a<\ell<\pi a2a<ℓ<πa there is one upper circular graph extremal with ℓ=2Rθ,\ell=2R\thetaℓ=2Rθ, whose endpoint constants are fixed by the chord. The semicircle limit leaves the C1C^1C1 graph class.

Lecture 48 frees the endpoint values and classifies the stationary free-end Dido arcs with parametrised curves, which admit the semicircle. It then lets the integration limits move, derives transversality and treats Fermat’s principle.
